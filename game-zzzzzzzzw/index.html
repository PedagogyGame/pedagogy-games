丛林
Jungle Run

Nine verbs stand between you and the far side of the valley. There are no arrow keys — the word is the control. See the pit, type 跳 tiao, and you jump. Miss it and the jungle takes a bite.

Easy leaves the pinyin under each character, so you can read it as you type — good for a first pass or for drilling the tones. Normal hides it and you recall it yourself.
