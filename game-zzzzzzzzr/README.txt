Ten Miles
A first-person walk of the empty Ming Great Wall, Jinshanling to Wangjing Lou and back.

How to play
1. Unzip this folder.
2. Do not double-click index.html (browsers block the game files that way).
3. Open a terminal in this folder and run:
     python3 -m http.server 8080
   Then visit http://localhost:8080
   Or drop the folder onto any static host (Netlify, GitHub Pages, etc.).

Controls
- Click / New Walk: start
- WASD: walk    Shift: faster    Mouse: look
- Esc: pause (resume, settings, title)
- Progress saves in the browser.

Click to walk. Empty wall. About ten miles out and back.
