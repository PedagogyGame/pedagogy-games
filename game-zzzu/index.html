Exact designs vary, but each of these twenty-eight has a counterpart in practically any standard household automatic dishwasher. The mechanical core is narrower still: tub, racks, spray arms, sump, filter, circulation pump, inlet valve, drain pump, heating system, detergent dispenser, door seal, sensors, and the cycle controller that sequences them.
